Course Take away

Mobile Web Development  ·  Spring 2026

What I Learned

Coming in, I had some familiarity with HTML and CSS from the previous course, but this course filled in a lot of gaps I didn't realize I had. The biggest shift was learning to think mobile-first, designing for the smallest screen first and working outward, rather than shrinking a desktop layout down after the fact. That change in mindset alone changed how I approach layout problems.

CSS Grid and Flexbox were probably the most practically useful things covered. I had been putting layouts together with floats and positioning before, and seeing how much cleaner grid-based design is made the older approaches feel immediately obsolete. The responsive resume project forced me to actually use those tools under real constraints, which was more valuable than any isolated exercise.

Responsive images and the srcset / picture element were things I hadn't considered seriously before. The idea that you'd serve different image assets depending on screen size and resolution seems obvious in retrospect but wasn't something I'd ever implemented deliberately. Same with structured data — Schema and JSON-LD aren't something you see on the surface, but understanding what they do and why search engines care about them opened up a part of web development I'd never thought about.

Bootstrap was useful to get exposed to even if I don't plan to use it as a first choice. Understanding how a CSS framework is structured — the grid system, the component library, the utility classes — made it easier to understand what Tailwind is reacting against. Getting a prototype up quickly using Bootstrap genuinely impressed me; the speed is hard to argue with when you're in early stages.

Google Analytics was new territory entirely. The distinction between accounts and properties, setting up data collection, and understanding what the reports are actually telling you about user behavior felt like a different kind of literacy than writing code — more analytical, more business-facing.

What I'd Like to hopefully Investigate Further Soon

I want to spend more time with JavaScript in a mobile context. The course introduced frameworks — Vue, React, Angular — but only at a surface level. I'd like to understand how state management actually works in a real application and why someone would choose one framework over another beyond personal preference.

The geolocation and Maps API section felt like the tip of something much much larger. Able to Build location-aware web applications seems genuinely interesting and I'd like to explore the Watch Position API in more depth and understand how you'd build something that behaves sensibly when GPS is unreliable or unavailable.

CSS custom properties took me not long to grasp and I want to go deeper and particularly around theming systems and how variables interact with JavaScript. The min(), max(), and clamp() functions also felt underused in my own work; building truly fluid layouts without breakpoints is something I'd like to get better at.

Ideas for Improvement

Honestly I do not have many complaints considering that the course covers a lot of ground and is really well-structured in my opinion. If anything just a bit more time on javascript but that's about it.
